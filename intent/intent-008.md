# Intent: remove the template creation functionality

## Problem
There new workflow does not require anything but a root _index page with a confluence page binding.  The whole template thing is just confusing.

## Proposed outcome
Remove the template stuff from settings.  Remove any functionality that creates a template note.  Remove any instructions talking about templates from either a readme or comments. 

We need to keep the frontmatter for newly bound notes.  There might be some comments or function naming that uses the word "template".  Keep the functionality and all the frontmatter properties the same, just rename it so it isn't referring to a template.
